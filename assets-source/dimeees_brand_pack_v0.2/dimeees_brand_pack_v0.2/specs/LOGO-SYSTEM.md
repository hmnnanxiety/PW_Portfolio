# dimeees Logo System

## 1. Primary wordmark

`dimeees`

- Render as native HTML text using Eudoxus Sans ExtraBold/Bold.
- Ink `#1A1A1A` is the base wordmark color.
- Keep the letterform treatment clean and professional.
- The playful identity comes from small accent assets rather than a novelty display font.

### Accent language

The original identity-board wordmark uses three memorable cues:

1. blue dot accent,
2. blue smile/underline gesture beneath the later `e` characters,
3. yellow ray marks near the final `s`.

These accents are supplied as standalone SVG files under `brand/accents/` so they can be positioned responsively.

## 2. Avatar / head mark

- Curly black hair is the strongest silhouette cue.
- Round glasses are mandatory.
- Expression should feel relaxed, slightly mischievous/confident, not overly cartoonish.
- Keep forms flat and simple enough to match the existing expression/action mascot system.

## 3. Expressive lockup

Hero/reference composition:

`[illustrated head] + [dimeees wordmark] + [small accents]`

Use the center-left Logo Lockup panel in the identity board as the main composition reference.

The lockup is an expressive brand composition, not a single flattened production image.

## 4. Responsive rule

Desktop may visually overlap the head with the beginning of the wordmark.
Mobile may stack/recompose the same elements.

Never rasterize the wordmark just to preserve the desktop layout.
