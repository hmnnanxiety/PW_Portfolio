# Eudoxus Sans

The owner-supplied, unmodified TTF files are kept in `src/fonts/`. The root layout uses `next/font/local` for Light 300, Regular 400, Medium 500, Bold 700, and ExtraBold 800. ExtraLight 200 is retained but not loaded.

`EudoxusSans-OFL.txt` preserves the copyright notice embedded in the supplied font's name table and the SIL Open Font License 1.1 text from https://openfontlicense.org/documents/OFL.txt. The embedded attribution names Stijn de Vries and The Plus Jakarta Sans Project Authors; it has been preserved verbatim rather than replaced with an inferred attribution. No font files were downloaded or converted.
